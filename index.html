04 / Privacy

Private work stays private.

MYRAA's planned public control plane handles install status, software updates, licences and announcements, not remote control of personal devices.

  • Your content stays off our dashboard

    No screen, chat, voice, contacts, files or keystrokes are collected into the MYRAA owner dashboard.

  • Reporting is opt-in

    Optional usage and crash reporting is off by default. You choose.

  • Honest about the network

    Local actions run on your device. Some AI features may use third-party network services.

06 / FAQ

Straight answers.

Is MYRAA finished?

No. MYRAA is beta software. Features may vary by device and setup, and you may hit rough edges.

Why is the download button disabled?

We only link verified GitHub Releases. Until a release with a checksum is published, the button stays off on purpose.

When are iPhone and Windows coming?

Both are in progress. Android is available first; iPhone and Windows will appear here when they are ready.

What does Rogue 18+ mean?

Rogue is unfiltered conversation for adults. The app asks for an 18+ confirmation before it can be used.

Do I need special hardware for Smart Home?

Yes. Smart Home controls your own ESP32 boards, and they need to be set up first.

When is Apex coming?

There is no date yet. Join the waitlist above and we will email you once, when it is available.
